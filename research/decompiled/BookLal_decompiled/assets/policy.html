User Data Policy

At BookLal app, we prioritize the privacy and security of our users' personal information. This User Data Policy outlines how we collect, use, store, and protect data, including images, particularly concerning the use of Google Firebase for image storage.

1. Collection of User Data

1.1 Profile Images: Our app offers users the option to upload a profile image. This image is used solely for personalizing the user's profile within the app.

1.2 Book Images: In our app, images of books are displayed in book listings. These images are provided to enhance the user experience and help users identify books of interest.

2. Usage of User Data

2.1 Profile Images: Uploaded profile images are securely stored on Google Firebase servers. They are used exclusively for displaying the user's profile image within the app and are not shared with any third parties.

2.2 Book Images: Images of books are also securely stored on Google Firebase servers. These images are used within the app's interface to visually represent the books listed. They are not used for any other purposes and are not shared externally.

3. Storage and Security

3.1 Google Firebase: We utilize Google Firebase to store user-uploaded images. Google Firebase employs robust security measures to protect against unauthorized access, alteration, disclosure, or destruction of user data.

3.2 Access Control: Access to user data stored on Google Firebase, including images, is restricted to authorized personnel only. We regularly review our security practices to ensure compliance with best practices and regulatory requirements.

4. User Consent

By using our app and uploading images, users consent to the collection, processing, and usage of their data as outlined in this User Data Policy. Users have the right to withdraw their consent and request the deletion of their data at any time.

5. Policy Updates

We reserve the right to update this User Data Policy periodically to reflect changes in our data practices or legal requirements. Users will be notified of any material changes to this policy.
