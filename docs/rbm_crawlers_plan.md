# Implementation Plan: South Asian RBM Crawlers

## Objective
Establish a new crawler infrastructure (rbm_crawlers) dedicated to extracting structured inventory data from the primary Regional Book Marketplaces (RBM) in South Asia.

## Key Targets
1. Kitabain (Pakistan)
2. UsedBooksFactory (India)
3. BookStand (India)
4. BookExchange.lk (Sri Lanka)
5. Booktionary (Bangladesh)
6. Sasto Kitab (Nepal)

## Tech Stack
- Python 3
- httpx / BeautifulSoup4 (Static)
- Playwright + Stealth (Dynamic)
